3. Datasets

Large raw files are not committed to GitHub (see .gitignore). We document sources, manifests, and how to reproduce local copies.

Primary — Snapshot Serengeti (supervised training)

  • Source: Dryad — Snapshot Serengeti (consensus_data.csv, all_images.csv).
  • Scale: millions of camera-trap images in the full archive; our manifest uses a labeled subset (see data/manifests/serengeti_manifest.jsonl).
  • Repo split used in experiments: 6,529 train / 2,142 validation images (balanced predator vs non-predator workflow).
  • Local JPEGs: download via scripts/download_serengeti_images.py → data/processed/serengeti_images/ (gitignored).

Domain adaptation — Path of Titans screenshots

  • Custom labels: 300 in-game screenshots labeled predator / non_predator for fine-tuning (240 train / 60 val).
  • Holdout: 10 labeled game screenshots for safety/threshold checks.
  • Location: team-collected assets under data/processed/ (not uploaded to GitHub due to size).

Secondary / deferred

  • Kaggle — Dinosaur Tactical Action Dataset (tactic CSV, optional): Kaggle link
  • Kaggle — animal-behaviour / animal-behavior-prediction: deferred large downloads — docs/deferred_large_datasets.md
